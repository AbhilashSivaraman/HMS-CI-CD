Step 1 - Create EKS Cluster

Since you're already experienced with EKS from your earlier HMS deployment, create a fresh cluster for the CI/CD setup.

Example:

eksctl create cluster \
--name rony-hms-cluster \
--region ap-south-1 \
--nodegroup-name rony-hms-nodes \
--node-type t3.medium \
--nodes 2

Why 2 nodes?

Eureka
RestaurantListing
FoodCatalogue
UserInfo
Order
ArgoCD

A single node becomes tight very quickly.

Step 2 - Verify Cluster
kubectl get nodes

Expected:

Ready
Ready


Step 3 - Create Namespace

kubectl create namespace rony-hms

Step 4 - Install ArgoCD

After EKS is running:

kubectl create namespace argocd

kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml

ALT

kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/v3.2.0/manifests/install.yaml

Then:

kubectl get pods -n argocd

Wait until everything is:

Running

Expose ArgoCD UI

kubectl patch svc argocd-server -n argocd --type=merge --patch='{\"spec\":{\"type\":\"LoadBalancer\"}}'

kubectl get svc -n argocd
